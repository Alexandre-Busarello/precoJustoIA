# Backlog global rules (read before starting any batch)

GLOBAL RULES (every batch):
- PRODUCTION SAFETY: the repo .env points DATABASE_URL/DIRECT_URL at the PRODUCTION Neon DB. Never run yarn build / npm run build (runs prisma db push), prisma db push/migrate/reset, psql against .env, or scripts in scripts/ (only scripts/local/* and scripts/check-*.sh are allowed). Any prisma/tsx command that touches a DB must inline DATABASE_URL=postgresql://postgres:local@localhost:55432/pja DIRECT_URL=postgresql://postgres:local@localhost:55432/pja. The dev server already runs at http://localhost:3100 on the local DB: do not start another on 3100 and do not kill it (a watchdog restarts it above 3 GB RAM; wait and retry). Never call payment/checkout, email-sending, or Gemini/AI generation endpoints (do not click 'Gerar', 'Pagar', 'Configurar com IA', etc.). Do not git commit.
- OWNERSHIP: edit/create/delete only inside your ownedPaths. Importing from anywhere is fine. If something outside your scope must change, do not edit it; list it in your final report.
- DESIGN SYSTEM: follow docs/melhorias-2026-09/reports/ux-ui.md sections 1-2 and 2.7 (tone). Tokens only: bg-background, bg-card, bg-surface, bg-muted, text-foreground, text-muted-foreground, border-border, text-brand/bg-brand/bg-brand-subtle, text-positive/negative/warning + bg-*-subtle. Remove bg-gradient-*, from-*/to-*, bg-clip-text, backdrop-blur, shadow-lg/xl/2xl (except overlays), font-extrabold/black, raw palette classes (bg-white, text-gray-*, text-blue-600, bg-green-50...), emoji in JSX, '!' and CAPS in UI copy, colored icon tiles. Delete legacy dark: classes in every file you touch (tokens handle dark mode). Semantic green/red only for variation/results, never for a static price. Numbers only via @/lib/format (formatBRL, formatBRLCompact, formatPct(fraction), formatDeltaPct, formatMultiple, formatDate, formatNullable) with tabular-nums; check the unit of every field (fraction vs percent) before formatting. Margin/upside via @/lib/valuation-metrics (marginOfSafety = 1 - P/VJ, upside = VJ/P - 1). Icons: lucide, size-4/size-5, strokeWidth 1.75, text-muted-foreground. Use the wave-0 components: Stat, SectionHeader, PageHeader, DataTable, InfoHint, AssetHeader, ScoreCard, AssetSectionNav, Badge variants (neutral/positive/negative/warning/brand). Compliance copy: never 'Compra', 'Venda', 'Sinal de compra', 'Região segura', 'garantida', 'preditiva', 'único(s) no mercado/Brasil', 'melhores ações', 'recomendação' (except inside 'não é recomendação'); use 'Abaixo do preço justo', 'Acima do preço justo', 'Dentro da faixa estimada', 'estimativa'. Sentence case pt-BR. Trial is 1 day (owner decision): never change trial length or copy it as longer.
- TITLES/SEO: the root title template is '%s | Preço Justo AI'. Strip trailing '- Preço Justo AI', '| Preço Justo AI', '| Preço Justo' from metadata titles in files you own. Remove any aggregateRating/fabricated review markup you find in your files.
- MOBILE: no horizontal scroll at 320/360/390 px; tap targets >= 44 px; inputs/selects/textarea >= 16 px below md; wide tables use DataTable (sticky first column + horizontal scroll) instead of overflowing; nothing fixed may cover content (reserve padding).
- DARK MODE: every surface you touch must be legible in dark. Force dark in tests with the screenshot flag --theme dark (the toggle stays hidden until wave 3).
- VALIDATION before finishing: (1) npx tsc --noEmit: zero errors in your files (ignore errors that are only in files other batches own and mention them in the report); (2) npx eslint <your changed files>: no errors; (3) bash scripts/check-ui.sh <your changed files>: passes; (4) npx tsx --test <your test files> when you add logic; (5) screenshots: npx tsx scripts/local/screenshots.ts --base http://localhost:3100 --out <SCRATCH>/shots/<batch-id> --routes <your routes> --auth both --viewports small,mobile,desktop --theme both. If the script says the seed is stale (new day), re-seed once: DATABASE_URL=postgresql://postgres:local@localhost:55432/pja DIRECT_URL=postgresql://postgres:local@localhost:55432/pja npx tsx scripts/local/seed-local.ts. Test users: premium@local.test and free@local.test, password Local123!. Mobile metrics helpers (sticky height, overflow, tap targets) exist in docs/melhorias-2026-09/tools/mobile-audit.mjs.
- FINAL REPORT: list changed files, acceptance criteria met/not met with evidence (screenshot paths, numbers), and any out-of-scope follow-ups.
